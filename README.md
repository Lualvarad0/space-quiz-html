# Órbita — Quiz de exploración espacial

Órbita es un quiz interactivo en español para poner a prueba tus conocimientos
sobre la exploración espacial. Incluye preguntas de opción múltiple,
seguimiento del progreso, puntuación y explicaciones para las respuestas.

## Ejecutar en local

No necesitas instalar dependencias ni iniciar un servidor. Abre `index.html`
directamente en un navegador web.

## Publicación

El sitio se despliega en GitHub Pages automáticamente cuando hay cambios en la
rama `main`. También puedes iniciar el workflow **Deploy to GitHub Pages**
manualmente desde la pestaña **Actions** del repositorio.
